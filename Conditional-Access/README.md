# Microsoft Entra Conditional Access

Welcome to the Conditional Access section of the Zero Trust Blueprint Hub.

This repository contains Microsoft Entra Conditional Access policy configurations demonstrated in the Zero Trust Blueprint Hub YouTube series.

These policies are designed to help organisations implement Zero Trust security principles by controlling access to Microsoft 365 resources.

## Available Policies

### Require Compliant Windows Devices

Enforces device compliance requirements using Microsoft Entra Conditional Access and Microsoft Intune.

This policy helps ensure that Windows devices meet your organisation's security requirements before accessing protected resources.

## Deployment Recommendations

- Review and customise policies before deployment.
- Start with a pilot group.
- Use Report-only mode before enforcing policies.
- Review Microsoft Entra sign-in logs to identify potential access issues.
- Exclude emergency access accounts to prevent administrative lockouts.
- Test access from compliant and non-compliant devices.

## Important

These configurations are provided for educational purposes and should be reviewed and tested before deployment into production environments.

Always ensure you have appropriate emergency access procedures in place.
